# Andrew Olijarczyk – Engineering Portfolio

This repository contains the source code and static assets for my professional engineering portfolio. The site highlights my hands-on experience in mechanical and aeronautical design, control systems, and product development.

**🌐 Live Site:** [olijarczyk.com](https://olijarczyk.com)

## 📌 Repository Overview

This static site serves as a central hub for my technical documentation, academic reports, and 3D CAD modeling projects. It utilizes a custom web-based 3D viewer to interactively display my design work.

### Key Contents
* **`/models`**: Contains production-ready STL files, including the main assembly for a reconnaissance UAV capstone project and structural mounts. 
* **`/reports`**: Hosts comprehensive technical documentation, including:
  * Heat Transfer Analysis Report
  * PID Pendulum Control System Report
* **`/js`**: Includes custom scripts to power the interactive 3D model viewer (`viewer.js`) and manage the CAD asset library (`models-list.js`).
* **`/resume`**: Contains the most recent, web-safe copy of my professional resume.

## 🛠️ Tech Stack & Deployment

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Model Rendering:** WebGL/Three.js (via custom viewer implementation)
* **Deployment & Hosting:** Continuous deployment pipeline integrated with GitHub and hosted via Cloudflare Pages for high-speed global delivery.
